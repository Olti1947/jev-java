# Contributing to jev-java

First off, thank you for considering contributing to `jev-java`! It's contributions like yours that make this SDK a robust, high-quality tool for the community.

---

## Code of Conduct

Please help us keep this project open, welcoming, and inclusive. Treat all contributors and users with respect.

---

## How Can I Contribute?
Before making a PR please create a new issue.

### 1. Reporting Bugs
Before opening a new issue, please check the existing issues to see if the bug has already been reported.

When opening a bug report, please include:
- A clear, descriptive title.
- Steps to reproduce the behavior.
- Expected vs. actual results.
- Your Java runtime version (`java -version`) and OS.

### 2. Suggesting Enhancements
Feature requests are welcome! Please open an issue with the tag `enhancement` and describe:
- The problem your proposed feature solves.
- How you envision the API usage looking in practice.
